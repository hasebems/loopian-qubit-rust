
* MFT2026 の記録

- 土曜日に二つの不具合
    - Loopian::App からの伴奏の LED 点灯が3箇所光ってしまう
    - Violin が音残りする
    - Violin の圧力センサーが正常に動作しないとほとんど音が出なくなる

- 日曜日の対応
    - EXP_MIN_VALUE を 40 -> 72 にして、触るだけでそこそこの音が出るようにする
    - 二つの QUBIT が、それぞれ App に入力され、また Camelot に入る状況を変える
        - Violin 側の QUBIT の Device 名を変更し、PC の MIDI スタジオで削除して再接続
        - Camelot の入力を Violin の QUBIT のみにする
        - 当然 App に入る QUBIT は Piano のみになる
        -> 音残りが（ほとんど）無くなった
    - 上記対応で、Violin 側が全く鳴らなくなって、かなりの時間テンパった
        - 原因は QUBIT を Violin Mode にしていなかった
    - 3箇所光る問題は解決せず

- 教訓
    - 同じものが複数ある場合、ハードウェアの識別が必要
        - Piano 側と Violin 側を、ファームは同じでも、DipSw 等で処理が分けられる
    - 会場はうるさいことが多いので、ダイナミックレンジは狭いほうがいいかも

- 今後に向けて
    - 非常に反応の良いタッチセンシング状況を作る
        - 近接でも反応するくらいが望ましい
        - 接点はやすりで極限まで薄くする
        - ベロシティを取ることができるかも
        - 普通に触った時が普通の音量
            - そこからさらに大きく
            - そこからさらに小さく
    - タッチセンサーの反応の均一化、事前キャリブレーション
    - 非常に反応の良い圧力センシング環境を作る
